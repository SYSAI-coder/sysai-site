SYSAI 企业介绍网站 + 隐私政策部署指南

重要：发布前务必完成以下事项：
1. 打开 privacy.html，替换两处明显的「CONTACT EMAIL MUST BE ADDED BEFORE PUBLICATION / 正式发布前需填写有效的联系邮箱」为公司真实、可用的联系邮箱。
2. 核对隐私政策是否符合 SYSAI 实际使用和保存 Amazon/WPS/AI 数据的方式，特别是 AI 第三方服务、数据保存、删除、访问控制和 Amazon Ads 使用权限。必要时请法律或合规人员审阅。
3. 核对公司的正式英文名称是否为 Guangzhou Jizhi Technology Co., Ltd.，若公司采用不同法定英文译名，请统一修改网页。

GitHub Pages 免费发布方法：
1. 注册/登录 github.com。
2. 创建一个 PUBLIC repository，建议名称 sysai-site（只上传公开网页文件，绝不可上传 API keys、token 或 .env）。
3. 上传 index.html、privacy.html、style.css 到仓库根目录。
4. 进入仓库 Settings → Pages。
5. Build and deployment → Source 选择 Deploy from a branch。
6. Branch 选择 main、Folder 选择 /(root)，点击 Save。
7. 在 Pages 设置里查看生成的真实 HTTPS 地址。格式通常为 https://你的GitHub用户名.github.io/sysai-site/privacy.html
8. 用未登录 GitHub 的无痕浏览器访问上述 privacy.html，确认任何人都能打开，才填到 Amazon Consent Privacy Notice URL。

注意：这只是静态信息展示网站，不会自动连接 Seller Central 或 Amazon Ads，也无需配置网站后端。
